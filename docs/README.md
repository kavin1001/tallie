## Keeping this live

**October 11 repository update:** the founder authorized uploading all code and explicitly chose to keep `kavin1001/tallie` public. Development work is being published on `codex/natural-sandbox`; this supersedes earlier local-only push restrictions. Production deployment remains subject to local testing and explicit release approval. Historical verification and release notes below retain their original scope.

The founder requested temporary phone-only signup/sign-in for the manual-split preview (ADR-026). This is scoped to marked demo accounts and does not weaken existing passkey identities or enable money movement. See the identity and deployment guides for configuration, transition and **314-test** verification. Hosted release status is recorded in the tracker.

Update the affected design section and tracker with each material build change. Preserve old decisions when superseding them. Record verification at the level actually demonstrated: docs, local model/database, sandbox, or live pilot. Link implementation/tests when marking work implemented. Keep secrets and real customer information out of the repository.

The repository contains a local Tallie account app with persistent phone-bound identities, required passkeys, recovery, contacts, private invitations, real shared-expense records, receipt capture, and durable Messages workflows. Four runnable roles share PostgreSQL and application services: web, maintenance, receipt processing, and messaging. See the root [run guide](../README.md) and [implementation tracker](technical/implementation-tracker.md) for the current integration state.

The free account/manual-split preview is live at [tallie-web.onrender.com](https://tallie-web.onrender.com), backed by private Render PostgreSQL and the now-public [kavin1001/tallie repository](https://github.com/kavin1001/tallie). The hosted phone-demo release passed 314 local tests and Linux CI. A constrained container smoke and live HTTPS/session/access checks also passed at their recorded releases. Fresh phone-demo signup and two-person invitations are the next device checks. The web service sleeps when idle; this database expires October 26, 2026.

AWS storage remains deferred because account-specific free-plan coverage was not confirmed. Receipts, the Messages agent and payments are disabled in this deployment. Natural production integration, final-domain device signup/recovery, live messaging callbacks/media/delivery, HEIC and full redacted receipt sharing remain gates. Demo payments stay confined to the separate local simulator and are unavailable on the hosted preview.

Natural P2P approval is founder-confirmed; production setup and payment readiness remain pending.
